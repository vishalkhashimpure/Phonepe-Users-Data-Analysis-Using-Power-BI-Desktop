Step 2: created a Date Table

1. Save the file with a proper name.
2. if you have a date column in your dataset then create one separate table for date using dax functions for better result.
3. now go to table view in left side screen and click in table view then you will in a tab section table tools there is a option for New table click on that and now give the dax functions.
4. using this dax formula create a column:
	Date_Table = ADDCOLUMNS(CALENDAR(MIN(All_Transactions[Date]),MAX(All_Transactions[Date])),
	"Year",YEAR([Date]),
	"Month no.",MONTH([Date]),
	"Month name",FORMAT([Date],"mmm"),
	"Querter","Q"&FORMAT([Date],"Q"),
	"Weekday",FORMAT([Date],"dddd"),
	"Day no.",WEEKDAY([Date],2),
	"Weekend",
	IF(WEEKDAY([Date],2)>=6,"Weekend","Weekday")
	)
5. importance of creating month no. and day no. columns it will help to sort the months and days into ascending and descending order.

	     2. total transactions count = COUNT(All_Transactions[Transaction_ID])
