Step 2: created a Date Table

1. Save the file with a proper name.
2. if you have a date column in your dataset then create one separate table for date using dax functions for better result.
3. now go to table view in left side screen and click in table view then you will in a tab section table tools there is a option for New table click on that and now give the dax functions.
4. using this dax formula create a column:
	Date_Table = ADDCOLUMNS(CALENDAR(MIN(All_Transactions[Date]),MAX(All_Transactions[Date])),
	"Year",YEAR([Date]),
	"Month no.",MONTH([Date]),
	"Month name",FORMAT([Date],"mmm"),
	"Querter","Q"&FORMAT([Date],"Q"),
	"Weekday",FORMAT([Date],"dddd"),
	"Day no.",WEEKDAY([Date],2),
	"Weekend",
	IF(WEEKDAY([Date],2)>=6,"Weekend","Weekday")
	)
5. importance of creating month no. and day no. columns it will help to sort the months and days into ascending and descending order.

Step 4: create KPI's and Visuals.

1. create measures and save them in table measures. by selecting the measure table in home table section.
2. kpi's are 1. total transaction amount = SUM(All_Transactions[Amount])
	     2. total transactions count = COUNT(All_Transactions[Transaction_ID]) 
	     3. successful transactions = CALCULATE([total transactions count],All_Transactions[Payment_Status] = "successful")
	     4. success rate = DIVIDE([successful transactions],[total transactions count])
	     5. total users = DISTINCTCOUNT(All_Users[User_ID])
	     6. Transaction value previous month = CALCULATE([total transaction amount],DATEADD(Date_Table[Date],-1,MONTH))
	     7. Transaction value month over month growth% = DIVIDE([total transaction amount]-[Transaction value previous month],[Transaction value previous month],0)
	     8. total transactions previous month = CALCULATE([total transactions count],DATEADD(Date_Table[Date],-1,MONTH)) 
 	     9. total transactions month over month growth% = DIVIDE([total transactions count]-[total trans previous month],[total trans previous month],0) 
	    10. Previous Month Success Rate = CALCULATE([success rate],DATEADD(Date_Table[Date], -1, MONTH))
	    11. MoM Success Rate Change = DIVIDE([success rate] - [Previous Month Success Rate],[Previous Month Success Rate],0)
